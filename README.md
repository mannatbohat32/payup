# PayUp

PayUp is a lightweight, command-line Python application designed to simplify expense tracking and bill splitting among friends or teams.

## Key Features
- Expense Logging:Quickly input individual costs, descriptions, and user names.
- Smart Bill Splitting:Automatically calculates exact balances owed between group members.
- Clean Logic: Built purely using Python core structures (variable, string, input and functions).

##  Tech Stack & Concepts Used
- Language:Python 3
- Data Structures: Utilized dictionary mappings for dynamically tracking individual balances.
- Control Flow: Implemented robust loops for processing user inputs safely.

##  How to Run
1. Clone the repository or download the source code file.
2. Open your terminal or command prompt.
3. Run the application

##  What I Learned
Through this project, I mastered working with variable, string in Python, managing user input parameters, and organizing clean back end logic.
